Questions

Frequently asked questions

Proofpath is a hiring workspace for candidate profiles and portfolios, published jobs, consented applications, organization review, and structured assessment authoring. Candidate code execution and evidence reports are not available yet.
You can add a public GitHub repository link to a project. Proofpath stores the link but does not fetch repository contents. File uploads and a cloud IDE are not available yet.
You can describe project work and add technology labels. File uploads and document attachments are not available yet.
Live verification is not available yet. Hiring teams can author and publish an assessment, and candidates can review invitations and record consent; attempts cannot run code.
Challenge and interview recording is not implemented. Account security sessions can be viewed and revoked from the security page.
Candidates can publish or unpublish their public profile and choose which projects are public. Time-limited or password-protected portfolio links are not available yet.
